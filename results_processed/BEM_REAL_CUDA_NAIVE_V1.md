# 真实翼型表 BEM C/CUDA naive 开发基线（RTX 5090，v1）

## 1. 结论

已完成真实 OpenFAST 状态分布、NREL 5MW 叶片几何与 8 份真实翼型极线驱动的第一版 C17/CUDA C 求根开发基线。2,448,000 个普通节点状态上，严格串行 C17 二分求根耗时 6032.893 ms；RTX 5090 的同残差、同分支规则、同 80 次迭代上限内核 30 次均值为 47.283 ms，纯求解初步加速 127.59×。包含 H2D、kernel 和 D2H 的端到端时间为 51.558 ms，对应初步加速 117.01×。

这是 naive 二分法开发基线，不是方案要求的最终 C Brent/割线、GPU Brent/低分歧结果，也没有进行第二类 GPU 架构验证。

## 2. 数据身份

- 权威数据目录：`results_raw/20260824T060500Z_bem_real_dataset_v2`。
- 格式：`BEMREAL2`，SoA 小端 FP64；字段为 `Vx,Vy,Theta,PhiRef,PhiHintPreviousStep`，末尾为 `GeomPhiFlag`。
- 记录数：2,448,000；48,000 步×3 叶片×17 个普通节点。
- 数据集大小：100,368,032 bytes。
- 数据集 SHA-256：`2ed1dfc2a9c5cea03cccc163e90c8b7d6e84dc0efe950aca8b6a2b4902581b01`。
- OpenFAST 源输出 SHA-256：`9e70051bf4ae952ea3e955020d0346f1c65eb844d1071a499b3d150e6b876d21`。
- 性能案例关闭叶片三项柔性 DOF 和 `Skew_Mod`，但保留 600 秒真实 TurbSim 湍流、塔架/偏航运动、固定 12.1 rpm 转子、真实叶片几何与翼型表。关闭 skew 是为了让被测单变量残差和数据身份一致。
- 根端与最外端共 288,000 个固定诱导状态保留在原始 OpenFAST 输出中，但没有冒充普通求根实例。

## 3. 实现身份

- C17：`-O3 -march=native -std=c17`，严格 FP64，单线程。
- CUDA：CUDA 12.9 编译环境，`sm_120`，`-O3 --fmad=true --ftz=false --prec-div=true --prec-sqrt=true`。
- 8 个翼型共 829 个原始极线节点，采用 AeroDyn `AFTabMod=1` 与默认线性插值；没有用解析光滑函数替换翼型表。
- 残差、查表、hub/tip loss、高推力修正、物理有效性和三个求解区间由 CPU/GPU 共享同一头文件。
- CUDA kernel 使用 64 个寄存器、0 spill；本版本仍有提前退出和区间分支，未宣称低分歧。

## 4. 结果

| 指标 | 串行 C17 | RTX 5090 CUDA |
|---|---:|---:|
| 普通根数 | 2,448,000 | 2,448,000 |
| 纯求解时间 | 6032.893 ms | 47.283 ms（30 次均值） |
| 吞吐率 | 405,775 roots/s | 51,773,802 roots/s |
| 求解失败 | 0 | 0 |
| 纯求解加速 | 1× | 127.59× |
| 端到端时间 | — | 51.558 ms |
| 端到端相对串行 C 加速 | — | 117.01× |

CUDA 30 次 kernel 时间：中位 47.267 ms、最小 46.942 ms、最大 47.611 ms。

CPU 与 GPU 输出统计完全一致。相对 OpenFAST 公开 `Phi`：中位绝对角误差 `2.53e-9 rad`、p95 `2.67e-7 rad`；81,679 个状态（3.337%）大于 `1e-3 rad`。源码核查表明公开 `Phi` 在输出阶段会根据最终诱导重新计算，因此不能当作严格残差根的唯一 oracle；这些差异目前只作为工程交叉检查，不能写成 CUDA 错根率。
