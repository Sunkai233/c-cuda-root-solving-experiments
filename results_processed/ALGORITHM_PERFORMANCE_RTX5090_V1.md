# 严格 FP64 求根算法性能矩阵（RTX 5090）

## 1. 实验身份与完整性

- 正式运行编号：`20260824T015010Z_algorithm_performance_rtx5090`
- GPU：RTX 5090 GPU 0，compute capability 12.0，驱动 580.105.08
- 构建：严格 FP64；`--ftz=false --prec-div=true --prec-sqrt=true`，未启用 fast-math
- 方法：Brent–Dekker、护栏割线、护栏 Newton、护栏 Halley；Peng–Robinson 额外包含解析三次法
- 规模：五域 13 档，最大 `N=16,777,216`
- 计时：45 s 热预处理、10 次预热、30 次正式重复；分别保留 kernel 与 H2D + kernel + D2H
- 完整性：273 条汇总、546 个原始计时组、16,380 条原始重复；每组恰好 30 条
- 在线正确性：273 条汇总的错根总数为 0；最大抽查根误差为 2.354e-9，低于 1e-7 门限
- 统计：10,000 次按重复编号配对 bootstrap，95% 置信区间

## 3. 解释

- 算法优势具有明显领域依赖性，不存在一个在五域都最快的通用迭代器。
- BEM 中护栏割线最快；Halley 虽然在冻结校准集上迭代 p99 仅 6，但性能生成负载上更多护栏回退且二阶导数昂贵，最终比 Brent–Dekker 慢。
- Kepler 中 Halley 与 Newton 明显优于 Brent–Dekker，Halley 端到端仅比 Newton 快约 1%。
- PV 中 Newton 最快；Halley 少约三次迭代，但二阶导数计算抵消了这一收益。
- CSTR 的共同 256 点物理根隔离占主要成本，所以 Newton、割线和 Halley 的差距很小。这里不能用迭代次数单独推断性能。
- Peng–Robinson 解析三次法是最快且正确的专用方法。通用高阶迭代器没有超过它，符合负对照的预期；H2D/D2H 又把 kernel 的约 1.74× Halley差距压缩为端到端约 1.07×。

## 4. 公平性与边界

- 所有通用方法使用相同严格 FP64 残差、输入顺序、物理分支规则、停止阈值和输出结构。
- BEM 性能生成器限定在预先声明的光滑单根工作区间，同时持续变化叶尖速比、实度、桨距和阻力参数；没有通过复制同一样本扩充批量。
- CSTR 的分支扫描和 Peng–Robinson 的驻点根隔离均包含在 kernel 时间内。
- Halley 的二阶导数成本完整计时；CSTR 使用对一阶导数的中心差分，不能把它描述成全解析 Halley。
- 本矩阵比较 GPU 上的算法身份，不替代此前 CPU FP64 与 GPU 端到端扩展矩阵。
- 运行前 GPU 0 为 44°C，结束采样为 53°C；结束后的瞬时功率不是连续能耗轨迹。
