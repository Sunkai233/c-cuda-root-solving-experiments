# Framework-backed two-dimensional application figures

Figures 4--7 extend the OpenFAST visualization set to every non-BEM
domain.  Every curve, pixel and point is generated by an executed framework
calculation or a frozen exact benchmark table; none is a decorative concept
sketch.  Continuous-color panels retain the full computed field but are also
overlaid with value contours, the actual sampling lattice, operating markers
and direct regime labels so that color is never the only carrier of meaning.

## Figure 4 — Orekit elliptic-orbit batch

Panel (a) plots actual Orekit anomaly solutions as normalized Cartesian orbit
positions.  The benchmark stores `M in [0,pi]`; the lower half is the exact
Kepler symmetry reflection.  Panels (b,c) show the complete solved input plane
and the nine-decade high-condition corner.  Panel (d) compares all 3,000 Orekit
solutions with the independent 80-digit oracle.

Suggested caption: *Production-library realization of the elliptic Kepler
batch.  A catalog of orbital elements becomes an independent `(e,M)` solve
plane; the difficult near-parabolic corner amplifies binary64 error despite
machine-scale equation residuals.*

## Figure 5 — pvlib CEC module batch

The I-V curves and maximum-power surface are generated by pvlib 0.15.2 for the
CEC `Canadian_Solar_Inc__CS5P_220M` record.  The lower panels show all 3,000
frozen benchmark operating points and the independent pvlib Brent comparison.

Suggested caption: *Single-diode solves generated by a real CEC module
workflow.  Irradiance and cell temperature form a two-dimensional batch of
independent module operating points; the frozen suite additionally resolves
short-circuit, maximum-power, interior and open-circuit regimes.*

## Figure 6 — Cantera CSTR batch and exact scalar folds

Panels (a-c) are 1,512 converged states from a Cantera/GRI-Mech well-stirred
methane-air combustor.  Panel (d) deliberately remains the exact reduced scalar
benchmark: cold and hot histories select different physical roots through the
three-root interval.  The two models are adjacent but never conflated.

Suggested caption: *Batch structure and branch history in stirred-reactor
calculations.  The Cantera residence-time sweep exposes a sharp extinction
boundary, while the exact reduced benchmark shows why a multiroot CSTR solve
requires continuation history rather than an unordered root.*

## Figure 7 — CoolProp Peng-Robinson phase batch

CoolProp's PR propane backend supplies the saturation dome and physical state
data.  The exact PR cubic supplies the isotherms, root-count plane and three Z
branches.  The critical star is `(Tr,Pr)=(1,1)`.

Suggested caption: *Peng-Robinson phase-state batching in reduced coordinates.
The subcritical one-root/three-root boundary and liquid/unstable/vapor Z
branches show the physical classification performed per state; the fixed cubic
work also explains why this domain is a negative GPU end-to-end control.*

## Figure 8 — physical geometry and computational structure

This companion plate supplies the geometric context that is intentionally
absent from the field and validation plots. It links each batch directly to a
physical object and its algebraic solve: an orbital state on a Kepler ellipse,
the 96-cell CEC module and one-diode equivalent circuit, a jacketed and stirred
CSTR control volume, and a piston fluid cell with liquid/vapor phase geometry.
The displayed batch counts are read from the same executed tables as Figures
4--7 (3,000, 357, 1,512 and 18,271 states respectively).

Suggested caption: *Physical and computational structure of the four non-BEM
batch workloads. Each geometry maps a two-parameter operating state to an
independent nonlinear root: eccentric anomaly, terminal current, reactor
steady state, or compressibility factor. The replicated state markers and
model topology explain why the workloads are naturally batched without
reducing them to an abstract workflow diagram.*
